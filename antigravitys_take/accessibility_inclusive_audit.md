## 2. Accessibility Benchmarks (WCAG 2.1 AA+)

* Visual Contrast: Tested at 7.5:1 for all primary body text.
* Font Scaling: Use of `rem` and `clamp()` units ensures the site scales beautifully for users with vision impairment without breaking the "Masterpiece" layout.
* Interactive Targets: No button or link is smaller than 48x48px, accommodating users with limited motor precision.

## 3. Screen Reader Optimization

*   Semantic Landmarks: Proper use of `<main>`, `<nav>`, `<section>`, and `<article>` tags for logical skip-navigation.
*   Aria-Labels: Used extensively in the "Offerings Grid" to describe the visual "energy" of the bespoke celestial cards for non-visual users.

## 4. Cognitive Load Management

*   Single-Task Focus: The booking flow is isolated from decorative elements to prevent distraction.
*   Error Prevention: Form labels are persistent (no floating placeholders that disappear) to assist users with memory or attention difficulties.
