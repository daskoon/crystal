# UX/UI Specification: The "Shadow & Light" Design System

## 1. The Design Ethos
"Shadow & Light" represents the journey from confusion to clarity. Visually, this is achieved through high-contrast glassmorphism—frosted layers that "clear up" as the user engages.

## 2. Design Tokens
*   **Primary (Wisdom)**: `#643B9F` (Deep Astral Purple)
*   **Accent (Clarity)**: `#00f2ff` (Cyan Glow)
*   **Base (The Void)**: `#050507` (95% Black)
*   **Typography**: 
    *   *Headlines*: `Inter SemiBold` (Modern, Authoritative).
    *   *Signature*: `Yellowtail` (Personal, Human).
    *   *Body*: `Inter Light` (High readability, 1.8 line-height).

## 3. Component Specification
*   **The "Heritage Bar"**: A fixed navigation layer with 20% backdrop-blur, ensuring the CTA "Secure a Reading" is always visible.
*   **Interactive Offerings**: Cards using CSS `vibrate` or `pulse` subtle animations on hover to signal "Spiritual Energy."
*   **Phil's Prediction Section**: A high-authority signature section with a distinctive gold-leaf border (`border-image` CSS).

## 4. Accessibility & Mobile-First
*   **Touch Targets**: Min 48px for all booking actions.
*   **Contrast**: WCAG AAA standard for primary reading text (White on Deep Purple/Black).
*   **Responsive Flow**: Single-column vertical scroll on mobile to accommodate "one-hand navigation."
